# ADR-0004 — Disposition of the RFC Decision Set (RFC-0001–RFC-0017)

**Status:** Accepted
**Date:** 2026-08-02
**Decider:** Maintainer (Constitution Article 6)
**References:** PR #11 (ADR-0002/0003 + prompt library), PR #12 (RFC set +
`docs/rfc/RFC_ROADMAP.md` review), PR #13 (specifications), Issue #7

## Context

Per Constitution Article 7 and Baseline L-8, no RFC resolves anything
until its acceptance is recorded as an ADR. On 2026-08-02 the Maintainer
merged PR #12 (RFC-0001–RFC-0017 with its architectural review), declared
the accepted RFC set authoritative, directed specification work that
builds on the RFC recommendations (merged as PR #13), and directed
governance closure. Those decisions existed only as directives and merge
events; this ADR records them.

This ADR introduces no new choices. Where an RFC recorded no
recommendation, or framed options without choosing, the question is
recorded below as **remaining open**. The classifications follow the
RFCs’ own recorded recommendations and the merged
`docs/rfc/RFC_ROADMAP.md` review.

## Consequences

- Unknowns closed: U-2, U-5 (frame), U-7, U-9 (posture), U-11, U-12,
  U-13; U-3 closes jointly with ADR-0005. Interim rules recorded for U-6
  and U-10. U-8 deferred by decision. Still open: U-1 (D-01), U-14
  (procedurally routed into the RFC-0001 acceptance ADR), and the D-14
  remainder (memory/context artifact classes).
- RFC_ROADMAP Steps 1–9 are discharged by this record. Step 10 — the
  RFC-0001 identity decision — is now the sole controlling gate for all
  identity-dependent work.
- The RFC index (`docs/rfc/README.md`) is updated with a disposition
  column citing this ADR. Individual RFC files retain their
  submission-time `Status: In Review` headers: rewriting seventeen
  documents wholesale would violate the standing no-bulk-rewrite rule and
  risk altering technical content; the index plus this ADR are the
  authoritative disposition record.
- ADR-0002’s recorded follow-up (flip the three architecture `Status:`
  headers to Ratified) is discharged in the same pull request as this
  ADR.
- The `TODO(blocked-by: acceptance ADR for RFC-XXXX)` markers in `/specs`
  now have their referent; updating specification text is specification
  work outside this governance-only change.
