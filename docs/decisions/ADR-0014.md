# ADR-0014 — Ratification of the S05 Compiler Subsystem Boundary Contract Specification

**Status:** Accepted · **Date:** 2026-08-19 · **Author:** Maintainer · **Decider:** Maintainer (Constitution Article 6)

---

## 1. Context

Following the ratification of the S04 Stage 1 W-B interchange kernel (ADR-0013; `S04#5.1`–`S04#8.3`), Frontier Specification Language (FSL) established a canonical JSON interchange format (`S04#8.3`).

To unblock the compiler implementation program (**P04**) without violating the governing principle that implementations must never define language semantics or private subsystem boundaries (INV-2, INV-3, INV-11), **RFC-0021** was proposed and submitted under PR #49.

RFC-0021 specifies the minimal normative boundary contract for **S05 (Compiler Subsystem)**, addressing:
1. Strict UTF-8 RFC 8259 JSON input acceptance and schema version validation (`S05#1.1`–`S05#1.3`).
2. Machine-readable, deterministic diagnostics explicitly citing violated S04 clause identifiers (`S05#2.1`–`S05#2.4`).
3. CLI invocation (`fcos-compile`) and standard programmatic Python API contracts (`S05#3.1`–`S05#3.3`).
4. Deterministic Stage 1 Execution Bundle output emission (`S05#4.1`–`S05#4.3`).
5. Explicit deferral of executable bytecode, runtime ABIs, type checking, and package management to Stage ≥ 2.

PR #49 was accepted and merged into `main` by the Maintainer on 2026-08-19 (commit `a782b59`). This ADR serves as the authoritative governance record (Constitution Article 6, Article 7) ratifying the S05 specification and allocating permanent frozen clause identifiers.

---

## 2. Decision

The Maintainer decides:

1. **Acceptance of RFC-0021:** RFC-0021 is formally accepted as the governing basis for the S05 Compiler Subsystem boundary contract.
2. **Ratification of S05 Specification:** `specs/S05-compiler.md` is updated from `Status: In Review` to `Status: Ratified`.
3. **Allocation and Freeze of Clause Identifiers:** The thirteen normative clauses defined in RFC-0021 are allocated permanent, frozen identifiers:
   - `S05#1.1`: Input UTF-8 JSON format requirement.
   - `S05#1.2`: Schema version validation requirement (`"fsl/1.0"`).
   - `S05#1.3`: Deterministic JSON parse & rejection of duplicate keys.
   - `S05#2.1`: Clause-traceable diagnostics requirement (INV-17).
   - `S05#2.2`: Standard machine-readable diagnostic schema (`code`, `clause_id`, `message`, `path`).
   - `S05#2.3`: Deterministic sorting of diagnostic output.
   - `S05#2.4`: Prohibition of unratified semantic diagnostic assertions (INV-3).
   - `S05#3.1`: Standard CLI command interface (`fcos-compile`).
   - `S05#3.2`: Standardized process exit codes (`0`, `1`, `2`, `3`).
   - `S05#3.3`: Standard programmatic Python API interface (`compile_artifact`).
   - `S05#4.1`: Stage 1 Execution Bundle output format (`.fcos-bundle.json`).
   - `S05#4.2`: Execution Bundle document structure and required metadata.
   - `S05#4.3`: Deterministic compilation and byte-level reproducibility guarantee.
4. **Machine-Readable Clause Sidecar:** The S05 clause index sidecar `specs/S05-compiler.index.yaml` is instantiated conforming strictly to the ADR-0010 schema and verified by `tools/checks/check_clause_index.py`.
5. **Preservation of Explicit Non-Scope:** Executable bytecode codegen, runtime execution semantics, type-system typechecking, and package distribution remain explicitly deferred to Stage ≥ 2 and subsequent specification cycles.

---

## 3. Consequences & Program Impact

- **Gate Discharged:** Entry gate **`G-SPEC(S05)`** is officially **MET**.
- **Blocker Resolved:** Blocker **`B-06`** (Interface forms UNKNOWN) is resolved with respect to the compiler subsystem boundary.
- **P04 Unblocked:** Implementation package **`P04.1` (Compiler Implementation Plan & Skeleton)** is unblocked and authorized for execution on a dedicated implementation branch.
- **Traceability Guarantee:** All compiler implementation code and test fixtures in P04 must explicitly cite `S05#*` and `S04#*` clause identifiers in conformance with INV-17.
