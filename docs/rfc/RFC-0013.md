# RFC-0013 — Candidate Subsystem: Planner

**Status:** In Review · **Date:** 2026-08-02 · **Resolves:** — (subsystem introduction)
**Subsystem:** none (candidate; not in ratified Blueprint S1–S16)

## Summary

Decide whether a "Planner" subsystem enters the FCOS architecture. The
term appears only in the Maintainer-authored WP15 prompt file; it is
absent from the ratified Blueprint decomposition. Per Blueprint §13, a
new subsystem requires: this RFC, a Baseline/Blueprint amendment, and an
adoption ADR.

## Motivation

The WP15/Blueprint conflict flagged in PR #11: WP15 enumerates a Planner
among expected subsystems. Under ADR-0002 precedence the Blueprint
prevails, so the Planner is currently *not* part of FCOS. This RFC is
the honest vehicle for changing that — or for recording that it should
not change.

## Assumptions

- A-1: "Planner" refers to a system component, not an engineering
  process practice (process practices belong in governance, not the
  subsystem graph).
- A-2: If adopted, the Planner holds no defining authority over language
  meaning (A3 boundary, "the meaning line", is unaffected).
