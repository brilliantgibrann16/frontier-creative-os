# RFC-0016 — Candidate Subsystem: Agent Framework

**Status:** In Review · **Date:** 2026-08-02 · **Resolves:** — (subsystem introduction)
**Subsystem:** S16-adjacent (candidate; not in ratified Blueprint S1–S16)

## Summary

Decide whether an "Agent Framework" enters the architecture. Named in
WP15, absent from the Blueprint. This candidate carries hard ratified
bounds that any adoption must satisfy: CN-23 (no privileged AI channel),
INV-19 (AI participates through the same interfaces as humans), and the
deliberate Blueprint decision that the AI interface is an *absence* of
special interface.

## Motivation

WP15/Blueprint conflict (PR #11); WP21 prompt recorded the constraint
analysis.

## Hard Bounds (non-negotiable under current ratified corpus)

- Any agent acts through the same governed interfaces as a human
  contributor: PRs, reviews, issues (INV-19, CN-23).
- An agent framework therefore cannot introduce a privileged write path,
  a bypass of review gates, or agent-only authority. If a proposal
  requires any of these, it requires amending INV-19/CN-23 first — a
  separate, explicit act with its own RFC.

## Open Questions

   authority) — this RFC cannot be accepted while that flag is open.

## Recommendation (non-binding)

only with necessity evidence and explicit bound-compliance analysis.
