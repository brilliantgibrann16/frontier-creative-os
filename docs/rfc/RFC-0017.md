# RFC-0017 — Candidate Subsystem: Product UI

**Status:** In Review · **Date:** 2026-08-02 · **Resolves:** — (scope ruling + subsystem introduction)
**Subsystem:** S9 Developer Tools (partial) or none (candidate)

## Summary

Decide the scope boundary between S9 Developer Tools (ratified) and a
"Product UI" (named in WP15, absent from the Blueprint), then decide
whether anything outside S9 should exist.

## Motivation

WP15/Blueprint conflict (PR #11); WP23 prompt split the question exactly
this way and requested a Maintainer scope ruling.

## The Scope Question

S9 covers tooling that serves engineering work on FCOS artifacts
(editors' language support, diagnostics presentation, docs tooling).
A "Product UI" — an end-user-facing application surface — is a different
thing and is not in the ratified decomposition. The boundary ruling is
prior to any adoption decision:

| # | Ruling | Consequence |
| --- | --- | --- |
| U-A | Everything UI-shaped that FCOS needs is S9 tooling | No new subsystem; WP15 wording revised; UI work waits on S9's normal dependencies (D-01 for language-aware tooling) |
| U-B | A distinct end-user product surface is intended | New subsystem; necessity case + §13 amendment path; also the strongest signal that identity I-B/I-C is intended in RFC-0001 — the two decisions should be taken together |

## Necessity Case (for U-B only) — TODO

**TODO(blocked-by: Maintainer necessity evidence + RFC-0001):** a
product surface presupposes knowing what the product *is*, which is
exactly D-01. No filed need exists.

## Assumptions

- A-1: Under either ruling, no UI component carries language-meaning
  authority (A3 boundary).
- A-2: S9 tooling remains spec-consuming, never spec-defining (L-2).

## Open Questions

1. Maintainer scope ruling: U-A or U-B?
2. If U-B: does the product surface ship in this repository or its own
   (interacts with RFC-0003 taxonomy and repo-boundary questions)?

## Recommendation (non-binding)

Rule U-A now (it is reversible by later RFC); revisit U-B inside or
after RFC-0001, where the identity decision gives it meaning.
