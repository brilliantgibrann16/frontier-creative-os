# RFC-0018 — S04 Stage 0 Minimal Contract Clause Set (Amendment Proposal)

**Status:** In Review · **Date:** 2026-08-12 · **Resolves:** the P03.3 content gate
**Subsystem:** S4 · **Amendment proposal per S04 §Sequence flows, step 2**

## Summary

Propose the Stage 0 clause set for the ratified S04 container as a
minimal contract inventory: twelve clauses that restate, with stable
N-C identifiers, exactly the obligations already authoritative on
`main`, so the Stage 0 contract is internally traceable and
mechanically indexable (RFC-0008 M-B; ADR-0010). No syntax, grammar,
or semantics is proposed.

## Motivation

The ratified S04 container blocks clause content on P03.3 (Article 7
per-clause ratification), and ADR-0010 requires ratified clauses to
exist before the sidecar index may carry entries. The Maintainer's
explicit written directive of 2026-08-12 (Decision 1) fixes the P03.3
scope: only already-authoritative obligations, as the minimum
internally traceable set. This proposal compiles that set without
addition (CN-14).

## Assumptions

- A-1: The specification prose remains authoritative; the index is
  derived hygiene (AX-1; ADR-0010, decision 1).
- A-2: Amendment of ratified S04 text travels proposal RFC → recording
  ADR in the same decision cycle (S04 §State machines, §Sequence
  flows; INV-18).
- A-3: Clause IDs take the N-C hierarchical dotted form on the
  grandfathered document identifier `S04` — `S04#<major>.<minor>` —
  per RFC-0002's recorded N-C form (`SPEC-LANG-0007#3.2.1`) and
  ADR-0008; no namespace token is used or created.

## Exclusions (future content outside Stage 0)

Syntax, grammar, language and runtime semantics, compiler and
execution behavior, namespace tokens, implementation, performance, and
product requirements, architecture, and design policy: none is
proposed. Each enters, if ever, through its own amendment cycle
(RFC → ADR).

## Open Questions

None. CI gate integration of the index checker (P03.5) is explicitly
outside this proposal's scope: gate-set expansion is decision-level
(PROGRAM.md P01).

## Recommendation (labeled, non-binding)

Accept the twelve-clause minimal contract inventory exactly as the
2026-08-12 directive scopes it.
