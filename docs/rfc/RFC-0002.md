# RFC-0002 — Artifact Identifier and Namespace Scheme

**Status:** In Review · **Date:** 2026-08-02 · **Resolves:** U-2 (D-03)
**Subsystem:** cross-cutting · **D-01-independent: decidable now**

## Summary

Decide the identifier scheme for all governed artifacts (RFCs, ADRs,
specifications, clauses, tests, findings, risks, unknowns) such that it
survives 20 years, hundreds of RFCs, thousands of ADRs, and multiple
namespaces (Baseline scalability prerequisite: namespace-capable
identifiers; machine-checkable traceability, DP-12).

## Motivation

D-03 in the Decision Register; Blueprint §14 U-2. Clause-to-test
traceability (CN-9) and trace-closure audits (Doctrine §13) require
stable, parseable IDs before the first specification is ratified.

## Assumptions

- A-1: IDs, once assigned, are never reused or renumbered (INV-18
  analogue for identity).
- A-2: IDs must be resolvable mechanically without proprietary tooling
  (CN-26).

## Design Space

| # | Scheme | Trade-offs |
| --- | --- | --- |
| N-A | Flat sequential per type (`RFC-0001`, `ADR-0002`) — current de facto | Simple, human-friendly; no namespace capability; collision risk across future teams/domains |
| N-B | Namespaced sequential (`RFC-CORE-0001`, `SPEC-LANG-0007`) | Namespace-capable per Baseline requirement; requires ratified namespace registry; migration cost from N-A now trivial (2 ADRs, 0 RFCs exist beyond this set) |
| N-C | Hierarchical dotted clause IDs within documents (`SPEC-LANG-0007#3.2.1`) layered on N-B | Enables clause-level traceability (CN-9) directly; fragment stability rules must be defined (clauses may not renumber after ratification) |
| N-D | Content-addressed / UUID | Maximal stability, zero human ergonomics; violates GL-7 findability in practice |

## Open Questions

1. Namespace registry: who ratifies new namespaces (ADR each, or a
   delegated register)?
2. Do workspace mirrors display repo IDs verbatim (L-9 suggests yes)?
3. Clause-numbering freeze point: ratification or first citation?

## Consequences

- This RFC's own numbering (and this whole set's) is provisional; the
  acceptance ADR must state whether existing IDs are grandfathered
  (recommended by A-1) or migrated with a mapping table.

## Recommendation (non-binding)

N-B + N-C composite satisfies every recorded requirement
(namespace-capable, machine-checkable, human-findable) at near-zero
migration cost today. Flagged as recommendation only; decision is the
Maintainer's.
