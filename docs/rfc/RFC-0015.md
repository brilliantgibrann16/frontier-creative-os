# RFC-0015 — Candidate Subsystem: Context Engine

**Status:** In Review · **Date:** 2026-08-02 · **Resolves:** — (subsystem introduction)
**Subsystem:** none (candidate; not in ratified Blueprint S1–S16)

## Summary

Decide whether a "Context Engine" enters the architecture. The term
appears only in WP15 and is undefined in every ratified document: it has
no entry in the Baseline vocabulary (§9), no Blueprint subsystem, and no
filed need. Unlike RFC-0013/0016, even the *meaning* of the term is
unestablished, so a vocabulary definition (L-12: terms must be defined
before use in governed artifacts) is a precondition to any decision.

## Motivation

WP15/Blueprint conflict (PR #11); WP20 prompt recorded the vocabulary
gap.
