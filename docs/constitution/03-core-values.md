# Article 3 — Core Values

1. **Correctness over speed.** Working software with verified behavior takes precedence over rapid delivery.
2. **Clarity over cleverness.** Code and documentation are written to be understood by future contributors.
3. **Evidence over assumption.** Claims about the system must be verifiable from the repository. Unverified claims are treated as unknown, never presented as fact.
4. **Traceability.** Every significant decision is recorded and linkable from proposal to implementation.
5. **Simplicity.** Complexity must justify itself. Structure, tooling, and process are added only when a real need exists.
6. **Longevity.** Decisions favor the ten-year horizon over short-term convenience.
