# Repository Inventory (derived)

- Class: DERIVED, NON-AUTHORITATIVE -- informative documentation only
  (Baseline L-2). It defines nothing; on any conflict the repository
  source documents win and this file is regenerated.
- Ownership: P13 documentation pipeline
  (`docs/program/DOC_DERIVATION_CONVENTIONS.md`); never hand-edited.
- Generated by: `tools/docs/derive_repository_inventory.py`.
- Regenerate from the repository root: `python tools/docs/derive_repository_inventory.py`
  (or `python tools/docs/build_docs.py` to rebuild all derived docs).
- Output: `docs/derived/REPOSITORY_INVENTORY.md`.
- Sources:
  - Repository file tree (paths only; no file content is read).
- Limitations: mechanical extraction only -- no summaries, no
  interpretation, no status or disposition synthesis, no behavior
  claims.
- Paths carry no meaning here: a listing is not a status, an endorsement, or an authority statement.
- Excluded from the walk: `.git/`, `__pycache__/`, `.pytest_cache/`, `*.pyc`, and the output area `docs/derived/` (self-listing would break idempotent regeneration).
